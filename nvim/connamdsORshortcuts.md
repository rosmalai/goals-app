***nvim***

gg - straight to 1st line
V - select the line
G - goes to last line

gg -> V -> G - Select the whole file 
y - copy selected part 
p - paste the selected part

Space E - Toggle the file tree on/off
Ctrl + W W - Hop from the file tree to the editor and back
Space B D - Close a tab
Space B O - Close all other tabs but the current
Space G G - Launch LazyGit in a floating pane from the current directory
Space U W - Toggle soft wrap
Space S G - Search all files using grep with a preview
Space Space - Fuzzy-find any file in the current directory

gt - go between tab { next tab }
gT - previous tab

jump on next 4th line - 4 j 
jump before 9th line - 9 k

gg=G - format code structure

ctrl + ^ - previous file

space t - open terminal horizontally 
space T - open terminal vertically

Esc -. clt + w -. c - close terminal
